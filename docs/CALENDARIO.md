## Como produzir em lote

Um agente por lote de 10 artigos, com o prompt:

```
Leia /home/luiz-penha/Downloads/yooka/docs/CONTENT-GUIDE.md e siga o schema.
Escreva os artigos: <slugs>. Todos com category, description 140-160
caracteres, primeiro parágrafo de 40-70 palavras, passo a passo numerado
(5-8 passos), uma tabela, 4 perguntas de FAQ e links internos apenas da
lista garantida.
```

Depois de cada lote:

```bash
npm run build && npm run check:links && npm run og
git commit -am "conteúdo: <tema>" && git push
```

## Regra de ritmo

**2 artigos por semana, sempre no mesmo dia.** Consistência vale mais que
volume: o Google reindexa o que muda e o leitor volta por hábito.

## O que medir para escolher o próximo artigo

1. **Search Console → Consultas**: buscas que já geram impressão e ninguém
   clica → o título precisa mudar.
2. **Search Console → Páginas**: as páginas com mais impressões → valem mais
   artigos irmãos.
3. **Search Console → Calculadoras**: as calculadoras com mais cliques valem
   uma versão nova (outro formato de entrada).
4. **Analytics → saídas**: qual página entrega mais leitura até o fim — esse
   é o tema que rende.
